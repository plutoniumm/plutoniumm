Light Components

Minimal self contained web components built with TypeScript. Designed to be lightweight and easy to use. Drop in components that do one thing well.

<lt-mmd>
Renders markup diagrams and flowcharts using Mermaid.js. 
<script type="module" src="https://manav.ch/lt/mmd.js"></script>
<lt-mmd>
graph TD;
  A-->B;
  A-->C;
  B-->D;
  C-->D;
</lt-mmd>
graph TD; A-->B; A-->C; B-->D; C-->D;
<lt-split>
Creates a resizable split view between two panes. 
<script type="module" src="https://manav.ch/lt/split.js"></script>

The 'ratio' attribute defines the initial size ratio between the two panes. Additional styles, classes, and attributes are passed on. Additionally, split takes two optional parameters
ParameterTypeDescription
verticalbooleanIf true, the split is vertical (top/bottom). Default is horizontal (left/right).
disabledbooleanIf true, disables the resizing functionality.
<lt-split ratio="1:4">
  <div slot="a">1</div>
  <div slot="b">2</div>
</lt-split>
1
4
<lt-code>
Syntax highlighted code block using Highlight.js. 
<script type="module" src="https://manav.ch/lt/code.js"></script>

The 'language' attribute specifies the programming language for syntax highlighting.
<lt-code language="javascript" value="
  const hello = 'Hello, World!';
  console.log(hello);
">
</lt-code>
