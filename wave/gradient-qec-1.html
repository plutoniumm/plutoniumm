Correcting Quantum Errors 1: Complex Gradients

arXiv:2512.18061 • 19 December 2025 • next →

Nearly every quantum error-correcting code in use was designed by hand: pick an algebraic structure, derive the codewords, prove a distance. The results are clean objects, implicitly tuned for clean noise in which every kind of error is equally likely. Hardware is not clean. A real device might flip phases ten times more often than bits, and a hand-made code does not know that.

A quantum code is a short list of complex numbers; its quality against a fixed noise model is a single number, the fidelity. So fidelity is a function of the coefficients, and functions can be climbed: nudge each coefficient, re-measure the score, step uphill, repeat. Two things break on the way. Complex numbers refuse the usual notion of derivative, and naive steps walk the codewords out of quantum mechanics entirely. This part is about the first problem, and it ends with a gradient that passes every check thrown at it.

Breaking a qubit

A qubit is a pair of complex amplitudes, c0∣0⟩+c1∣1⟩c_0|0\rangle + c_1|1\ranglec0​∣0⟩+c1​∣1⟩ with ∣c0∣2+∣c1∣2=1|c_0|^2 + |c_1|^2 = 1∣c0​∣2+∣c1​∣2=1. Three basic accidents can happen to it: an XXX error swaps the amplitudes, a ZZZ error flips the sign of c1c_1c1​, and a YYY error does both at once. The noise model throughout is the Pauli channel: in each round every physical qubit independently suffers an XXX with probability pxp_xpx​, a YYY with pyp_ypy​, a ZZZ with pzp_zpz​, and survives untouched otherwise.

The oldest defence is repetition. Quantum states cannot be copied, but a state can be spread across three qubits, c0∣000⟩+c1∣111⟩c_0|000\rangle + c_1|111\ranglec0​∣000⟩+c1​∣111⟩. The two strings ∣000⟩|000\rangle∣000⟩ and ∣111⟩|111\rangle∣111⟩ are the codewords, written ∣0L⟩|0_L\rangle∣0L​⟩ and ∣1L⟩|1_L\rangle∣1L​⟩ for "logical zero" and "logical one". A single bit flip (c0∣010⟩+c1∣101⟩c_0|010\rangle + c_1|101\ranglec0​∣010⟩+c1​∣101⟩, say) is outvoted by the other two qubits, and the vote can be taken without ever reading the amplitudes themselves. With flip probability p=0.1p = 0.1p=0.1 per qubit:

P(no flip)=(1−p)3=0.93=0.729P(one flip)=3p(1−p)2=3×0.1×0.81=0.243P(vote fails)=3p2(1−p)+p3=0.027+0.001=0.028 \begin{aligned} P(\text{no flip}) &= (1-p)^3 &&= 0.9^3 &&= 0.729\\ P(\text{one flip}) &= 3p(1-p)^2 &&= 3 \times 0.1 \times 0.81 &&= 0.243\\ P(\text{vote fails}) &= 3p^2(1-p) + p^3 &&= 0.027 + 0.001 &&= 0.028 \end{aligned} P(no flip)P(one flip)P(vote fails)​=(1−p)3=3p(1−p)2=3p2(1−p)+p3​​=0.93=3×0.1×0.81=0.027+0.001​​=0.729=0.243=0.028​

The first two rows are handled correctly, so a 10% error rate becomes a 2.8% error rate. The catch: a ZZZ error on any one qubit turns c0∣000⟩+c1∣111⟩c_0|000\rangle + c_1|111\ranglec0​∣000⟩+c1​∣111⟩ into c0∣000⟩−c1∣111⟩c_0|000\rangle - c_1|111\ranglec0​∣000⟩−c1​∣111⟩, and the vote sees nothing wrong, because both strings are still unanimous. Codes that correct every single-qubit error exist; the smallest is the [[5,1,3]][[5,1,3]][[5,1,3]] code: five physical qubits holding one logical qubit, codewords made of sixteen five-bit strings each with carefully matched signs.

One more ingredient. After the noise acts, a recovery operation R\mathcal{R}R does the fixing, the generalisation of "take the vote and flip the minority qubit back". The recovery here is chosen once and then frozen: the Petz map, a general-purpose recovery written down directly from the code and the noise channel, and provably close to the best possible one. Freezing it matters: any improvement found later is an improvement of the code, not an artifact of a cleverer decoder.

The Petz map

Given the state ρ\rhoρ being protected (for a code, the average of the codeword states) and the noise channel N\mathcal{N}N, the Petz map is

R(σ)=ρ1/2 N† ⁣(N(ρ)−1/2 σ N(ρ)−1/2)ρ1/2 \mathcal{R}(\sigma) = \rho^{1/2}\, \mathcal{N}^{\dagger}\!\left( \mathcal{N}(\rho)^{-1/2}\,\sigma\,\mathcal{N}(\rho)^{-1/2} \right) \rho^{1/2} R(σ)=ρ1/2N†(N(ρ)−1/2σN(ρ)−1/2)ρ1/2

Read it as a quantum version of Bayes' rule: σ\sigmaσ is the noisy evidence, ρ\rhoρ is the prior, and the map answers "which input was most plausibly responsible for this output". It recovers the reference state exactly, R(N(ρ))=ρ\mathcal{R}(\mathcal{N}(\rho)) = \rhoR(N(ρ))=ρ, and Barnum and Knill showed it is never far from the best possible recovery for any state in the code space.

A code is a list of numbers

Five qubits live in a space with 25=322^5 = 3225=32 basis states, so a codeword is a list of 32 complex amplitudes:

∣0L⟩=a0∣00000⟩+a1∣00001⟩+⋯+a31∣11111⟩ |0_L\rangle = a_0|00000\rangle + a_1|00001\rangle + \cdots + a_{31}|11111\rangle ∣0L​⟩=a0​∣00000⟩+a1​∣00001⟩+⋯+a31​∣11111⟩

A code for one logical qubit is two such lists, ∣0L⟩|0_L\rangle∣0L​⟩ and ∣1L⟩|1_L\rangle∣1L​⟩: 64 complex coefficients, 128 real numbers, and that is almost all of quantum error correction: the algebra of code design is a very complicated way of choosing 128 numbers.

And any such choice can be scored. Encode with the codewords, apply the noise N\mathcal{N}N, apply the frozen recovery R\mathcal{R}R, decode, and ask what fraction of the original quantum information survived. That score is the fidelity F\mathcal{F}F, one real number between 0 and 1. For the [[5,1,3]][[5,1,3]][[5,1,3]] code under isotropic 5% Pauli noise with Petz recovery it comes out at F=0.783\mathcal{F} = 0.783F=0.783. How it is computed does not matter here: it is a black box, fillable by exact simulation, Monte Carlo sampling, or direct estimation on hardware.

So code design collapses to one sentence: find the 128 numbers that maximise F\mathcal{F}F. That is hill climbing in 128 dimensions, not physics, and it needs one tool, the gradient, the direction of steepest ascent. With no formula to differentiate, the gradient has to come from probing.

Slopes without formulas

The slope of any function at a point is measured the same way: move a little, see how much the output moved, divide. For one real knob xxx and a small probe δ\deltaδ,

slope=lim⁡δ→0f(x+δ)−f(x)δ≈f(x+Δ)−f(x)Δ \text{slope} = \lim_{\delta \rightarrow 0} \frac{f(x + \delta) - f(x)}{\delta} \approx \frac{f(x + \Delta) - f(x)}{\Delta} slope=δ→0lim​δf(x+δ)−f(x)​≈Δf(x+Δ)−f(x)​

This is a finite difference, and it needs nothing but the ability to evaluate fff twice.

The derivative that does not exist

Each coefficient aia_iai​ is complex, and the complex derivative is a stricter object than the real one. The difference quotient at a point z0z_0z0​ can probe from any direction θ\thetaθ in the plane,

q(θ)=f(z0+δeiθ)−f(z0)δeiθ q(\theta) = \frac{f(z_0 + \delta e^{i\theta}) - f(z_0)}{\delta e^{i\theta}} q(θ)=δeiθf(z0​+δeiθ)−f(z0​)​

Two directions, two answers, 2 versus 0, so no single number deserves the name "the derivative at 1". Write f=u+ivf = u + ivf=u+iv with uuu, vvv real: the requirement that all directions agree is the Cauchy-Riemann conditions,

∂u∂x=∂v∂y,∂u∂y=−∂v∂x \frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}, \qquad \frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x} ∂x∂u​=∂y∂v​,∂y∂u​=−∂x∂v​

For a real-valued function v=0v = 0v=0 everywhere, so both partial derivatives of uuu must vanish: the only real-valued functions of a complex variable with a complex derivative are constants. Fidelity is real-valued and not constant. Case closed.

Two knobs per coefficient

The fix is a century old: Wirtinger calculus replaces the one derivative with a pair,

∂∂z=12(∂∂x−i ∂∂y),∂∂zˉ=12(∂∂x+i ∂∂y) \frac{\partial}{\partial z} = \frac{1}{2}\left(\frac{\partial}{\partial x} - i\,\frac{\partial}{\partial y}\right), \qquad \frac{\partial}{\partial \bar{z}} = \frac{1}{2}\left(\frac{\partial}{\partial x} + i\,\frac{\partial}{\partial y}\right) ∂z∂​=21​(∂x∂​−i∂y∂​),∂zˉ∂​=21​(∂x∂​+i∂y∂​)

Trust, but differentiate: validating the gradient

A finite-difference gradient is easy to get subtly wrong, so before optimising anything, test it against answers known in advance. The repetition code comes in two flavours: the ZZZ code {∣000⟩,∣111⟩}\{|000\rangle, |111\rangle\}{∣000⟩,∣111⟩} above, which fights bit flips, and its mirror image the XXX code {∣+++⟩,∣−−−⟩}\{|{+}{+}{+}\rangle, |{-}{-}{-}\rangle\}{∣+++⟩,∣−−−⟩}, which fights phase flips. Under XXX-ZZZ symmetric noise they are one object seen from two angles, so the gradient machinery, which knows nothing of that symmetry, must report the same slope for both; and relabelling 0↔10 \leftrightarrow 10↔1 maps each code to itself, so ∥∇f∥\|\nabla f\|∥∇f∥ at ∣0L⟩|0_L\rangle∣0L​⟩ and ∣1L⟩|1_L\rangle∣1L​⟩ must match:

code‖∇f‖ at |0L⟩‖∇f‖ at |1L⟩
XXX0.9170.917
ZZZ0.9170.917
XXX, perturbed0.9110.911
ZZZ, perturbed0.9140.910

The bottom half is the matching negative control. Shift every coefficient by 0.05, renormalise, and the symmetry that forced those numbers to agree is gone, so the agreement should dissolve.

The last check is the probe size itself. At a sloppy δ=10−1\delta = 10^{-1}δ=10−1 the two repetition codes report different slopes, 0.98 against 0.88, pure finite-difference bias. Shrinking δ\deltaδ collapses both estimates onto the same 0.917, stable to three digits as δ\deltaδ approaches 10−410^{-4}10−4, the value then fixed for everything else. The δ\deltaδ selector in the widget above shows the identical effect on the toy: 0.769, then 0.667, then no further change.

A gradient, and a cliff

The validated gradient turns into an optimiser in one line. Pack each slope pair back into a complex number and move every coefficient at once, with learning rate η\etaη:

ai  →  ai+η(∂F∂xi+i ∂F∂yi) a_i \;\rightarrow\; a_i + \eta\left( \frac{\partial \mathcal{F}}{\partial x_i} + i\,\frac{\partial \mathcal{F}}{\partial y_i} \right) ai​→ai​+η(∂xi​∂F​+i∂yi​∂F​)

Run on the [[5,1,3]][[5,1,3]][[5,1,3]] code under 1% isotropic Pauli noise with Petz recovery (η=0.005\eta = 0.005η=0.005, 20 steps), the fidelities come out as

F∈[ 0.9821, 0.9828, 0.9825, 0.9825, 0.9826, …, 0.9838, 0.9838, 0.9839 ] \mathcal{F} \in [\,0.9821,\ 0.9828,\ 0.9825,\ 0.9825,\ 0.9826,\ \ldots,\ 0.9838,\ 0.9838,\ 0.9839\,] F∈[0.9821, 0.9828, 0.9825, 0.9825, 0.9826, …, 0.9838, 0.9838, 0.9839]

It works, and it wobbles: step three goes down, step eight crashes back to the start before recovering. The wobble hides something worse: codewords must stay unit-length and perpendicular, nothing in the update knows that, and once they drift the computed "fidelity" can exceed 1, a fiction the optimiser will happily chase. The gradient is validated; the space it moves through is not. Keeping the walk on the set of valid codes is part 2.
